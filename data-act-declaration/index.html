ClimatOn: Information About Data Generated by Connected Devices

  1. Information about the nature of the data generated by the connected product.

Types of Generated Data:

    1. Personal data:

      1. User geolocation (subject to user consent);

      2. User account data (when the user is logged into the mobile application).

    2. Non -personal data (device status data):

      1. On/off status;

      2. Temperature;

      3. Operating mode;

      4. Power level;

      5. Fan Speed;

      6. Filter life (resource).

    3. Customer usage data:

      1. User actions (changing settings, turning on/off).

    4. General environmental data:

      1. Temperature;

      2. Humidity;

      3. CO₂;

      4. Air Quality Index (AQI), PM2.5, PM10;

      5. Weather data.

  1. Estimated volume of data the connected product can generate.

    1. Data generated through user interaction: ~3 MB/day.

    2. Data generated while the device is in standby or powered-off: ~1 MB/day.

  2. Data Formats. Data generated by the devices:

    1. Collected in JSON format;

    2. Stored in a structured database;

    3. Transmitted via secure network protocols.

  3. Information on whether the connected product can generate data continuously in real-time.

    1. The majority of data is generated during user actions or device state changes.

    2. Some data is generated periodically (e.g., temperature sensor readings).

  4. Information on where the data is stored (e.g., on the device itself or on remote servers).

    Data is stored:

    1. On a remote server (located in Frankfurt, Germany).

    2. On the device itself (data is stored temporarily and overwritten when a new state is recorded).

  5. Information on the data retention period (Description of the Implemented Solution — Direct Access, API, or Portal).
    Data is stored:

    1. For as long as necessary to provide services.

    2. Until the user deletes their account or withdraws consent.

  6. Information on how users can access the data.

    1. The user may request a data export by sending a request to the email address   smartapp@cladswiss.com   or by completing the form on the portal:   https://app.prighter.com/portal/15929131527

  7. Information on how users can retrieve (export) the data.

    1. To receive a data export, the user must:

1. Visit the official website: https://climaton.app.

2. Navigate to the «Contacts» section.

3. Send a request to  smartapp@cladswiss.com.

The user is required to be logged into the ClimatOn app and to provide their phoneID in order to access their data.

To locate your phoneID in the ClimatOn App, navigate to: App → Support → About App → Phone ID.

    1. Alternatively:

        1. Proceed via the link contained in the Privacy Policy: https://app.prighter.com/portal/15929131527;

        2. Fill a request form;

        3. File a request with user credentials.

  1. Information on how users can delete the data.

    1. On-Device Deletion: restore the device to its factory settings.

    2. Local App Data Deletion: Uninstall the application to remove locally stored data.

    3. Cloud Data Deletion: The user can delete their application account at any time to remove cloud-stored data.

  1. Information about Terms of Service.

    1. The Terms of Service are available at: https://climaton.app/privacy

  2. Information about service quality.

APIs are used for data exchange between devices, the mobile application, and the server, including device status, user commands, and user geolocation (if permission is granted). APIs are also used to receive data from external services, such as weather and air quality indicators (e.g., ambient temperature, AQI, PM2.5, PM10).

SDKs are used to implement mobile application functionality, including device control, data processing, and server interaction.
